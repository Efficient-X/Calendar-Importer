# Security Policy

Please report security problems through GitHub's private security advisory feature:

https://github.com/Efficient-X/Calendar-Importer/security/advisories/new

Do not post private calendar feed URLs, calendar contents, access tokens, or unredacted screenshots in a public issue. A private iCal/ICS link can allow anyone holding it to read the associated calendar.

For ordinary bugs, use the GitHub issue tracker and include the Calendar Importer version, Obsidian version, device, calendar provider, and a sanitized error message.
