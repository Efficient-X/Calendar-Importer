# Commands

Calendar Importer adds a few commands to Obsidian:

- `Calendar Importer: Sync now`
- `Calendar Importer: Open calendar note`
- `Calendar Importer: Clear sync cache`
- `Calendar Importer: Rebuild calendar note`

For normal use, `Sync now` and `Open calendar note` are the two you will reach for most.

You can give it a hotkey here:

```text
Settings > Hotkeys
```
