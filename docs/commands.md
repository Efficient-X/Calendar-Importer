# Commands

Calendar Importer registers these Obsidian commands:

- `Calendar Importer: Sync now`
- `Calendar Importer: Preview next sync`
- `Calendar Importer: Clear sync cache`
- `Calendar Importer: Rebuild calendar note`

You can assign hotkeys in:

```text
Settings > Hotkeys
```

For day-to-day use, `Sync now` is the most useful command to bind.
