# Commands

Calendar Importer adds a few commands to Obsidian:

- `Calendar Importer: Sync now`
- `Calendar Importer: Open calendar note`
- `Calendar Importer: Reopen completed calendar tasks from the last 24 hours`
- `Calendar Importer: Reopen all completed calendar tasks`
- `Calendar Importer: Clear completed calendar tasks`
- `Calendar Importer: Clear sync cache`
- `Calendar Importer: Rebuild calendar note`

For normal use, `Sync now` and `Open calendar note` are the two you will reach for most.

If you accidentally tick something, use one of the reopen commands. The recent option is the neat little undo button; the all option is the big broom.

You can give it a hotkey here:

```text
Settings > Hotkeys
```
